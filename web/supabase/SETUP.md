# 越聊：免费方案接入说明

当前代码可直接继续使用原网址，不需要购买服务器。未配置时，“设置 → 消息通知与来电提醒”会明确显示尚不可用，不会假装已开启锁屏推送。

## 1. 架构

- PWA：主屏幕图标、安装信息、Service Worker、系统消息与来电通知。
- Cloudflare Worker（现有 Sites 托管）：验证设备凭证与好友授权，发送加密 Web Push，读写 Supabase。
- Supabase 免费项目：保存推送订阅和云端来电记录。前端不直接访问这些表。
- 保留已有 Cloudflare D1：设备身份、好友授权、离线待收消息，避免现有好友与离线消息在迁移中丢失。当前不是完整的 Supabase 账号/消息迁移。
- WebRTC/PeerJS：沿用现有语音、视频和双语字幕实现，媒体不经过 Supabase。

## 2. 创建免费 Supabase 项目

在 supabase.com 创建 Free 项目，在 SQL Editor 执行本目录 `schema.sql`。表启用 RLS，没有任何浏览器读写策略。Worker 使用 service_role；不要关闭 RLS，不要把 service_role 发到聊天、放到网页 JS 或提交 Git。

在项目设置取得 Project URL（例如 https://xxxx.supabase.co）和 service_role 密钥。此版本不需要前端 anon/publishable 公钥，因为所有请求均由 Worker 校验后转发。

## 3. 生成 Web Push 密钥

在自己的电脑/安全终端运行：

```sh
node scripts/generate-vapid.mjs
```

输出公钥、私钥和邮件地址示例。把 VAPID_SUBJECT 改成自己的 `mailto:邮箱`。私钥仅用于 Worker；公钥可发给客户端。密钥保持稳定，轮换后设备需重新订阅。

## 4. 配置 Worker 运行时变量

在现有 Sites 的运行时环境设置中安全配置以下五项，然后重新部署该版本：

```
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY
VAPID_SUBJECT
```

代码仓库 `.env.example` 只是字段说明，不会上传真实密钥。不要把密钥粘贴到好友聊天中。原 D1 的 DB 绑定保持不变。Supabase API 连接失败时已有 WebRTC 和 D1 文字消息仍可使用；新云端呼叫会显示错误。

## 5. iPhone 开启与验证

1. 使用 iOS/iPadOS 16.4 或更新版本，在 Safari 打开原网址。
2. 分享 → 添加到主屏幕，再从桌面图标打开越聊。
3. 打开“设置 → 消息通知与来电提醒”，点击开启并允许系统通知。
4. 两台设备先在线连接一次，让双方登记设备与好友授权。演示好友不发送真实推送。
5. 甲锁屏，乙发送文字/图片/语音消息；甲应收到系统通知。点击后读取 D1 中暂存的消息。
6. 乙分别发起语音和视频来电，甲点击通知打开页面，看到来电者并明确点击接听。音视频权限仍由浏览器询问。
7. 不接听等待 60 秒，再打开“通话”，应看到未接记录；关闭后再次打开仍保留。
8. 前台点按一次页面以启用音频，再验证来电铃声、接听、拒绝及铃声停止。
9. 双方实际通话并说中文/越南语，验证视频、语音和左右双语字幕未受影响。

PWA 锁屏来电是普通系统推送，不提供 iOS 原生 CallKit 全屏来电。不能保证关闭页面后持续响铃，也不能绕过静音、专注模式或系统投递策略。点击通知只打开接听页面，不自动取得麦克风或摄像头。

## 6. 免费额度与保留策略

未购买任何套餐或服务器。Supabase、Cloudflare/Sites、信令、TURN 和翻译均有各自限制；免费额度及休眠规则以服务商当前条款为准。免费 Supabase 项目休眠时推送和云端来电会不可用，需恢复项目。

页面可见时每 5 秒读取最多 40 条通话；后台停止轮询，依赖推送。不接听的来电记录一开始就已写入数据库；打开页面时把超过 60 秒仍未接通的记录转为 missed，不依赖网页一直运行。列表保留最近 40 条，本机通话记录也只保留 40 条。Supabase 建议设置每周清理超过 30 天记录的 SQL Cron（schema.sql 已有语句）；没有启用定时清理时数据库记录会继续累积。

现有 D1 待收消息最多保存 30 天，每个收信箱上限 300 条。推送不包含聊天正文，仅提示有新消息；订阅失效返回 404/410 时删除。当前未加入推送重试队列，第三方投递失败时仍可打开网页补收消息、查看来电记录。

设备凭证仍保存在本机浏览器；当前尚无正式账号、密码找回或跨设备身份恢复。生产化前优先补齐账号恢复与好友屏蔽，并完成 iPhone 双机实测及 TURN 跨运营商验证。

## 7. 当前验证范围

自动化覆盖已有通话/字幕功能、设备鉴权、好友授权、来电状态权限、未接过期、记录持久化/去重、系统通知内容与点击入口。没有配置真实 Supabase 项目和 Apple Web Push 订阅之前，无法宣称 iPhone 锁屏实机投递已通过。

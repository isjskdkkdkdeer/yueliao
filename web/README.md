# 越聊 YueLiao · 中越双语社交平台 1.0（限量公测）

响应式静态网页，中越双语聊天、在线好友、语音消息和 WebRTC 语音／视频通话。

## 使用

打开网页会自动使用本机保存的好友号连接聊天服务；退出后重新进入、从后台返回或网络恢复时会自动重连。已添加的好友会自动尝试恢复连接，保持页面打开时也会定期检查尚未连接的好友。好友只有在双方实际握手成功后才显示在线，聊天服务上线本身不代表好友已连接。

右上角可以切换中文／Tiếng Việt 界面；选择保存在当前浏览器，与说话语言分别设置。通话页分别选择“我说中文”或“我说越南语”，“我说的”和“她说的”字幕各自显示，分别列出原文与译文；等待说话时也保持两块区域可见，字幕背景透明，手机和宽屏均固定左右显示：左边是“我说的”，右边是“她说的”。字幕包含通话标识、语句序号和更新版本，避免两边发言及异步翻译互相覆盖。

首次进入可以和标注为“演示好友”的 Linh 体验预设自动回复。在“添加好友”中交换好友号，双方打开网页并连接聊天服务后可进行真实聊天。站点已按所有者要求开放访问。

文字聊天及历史仅存在当前浏览器；不支持离线消息、多设备同步、账号恢复。公共 PeerJS 提供信令；媒体及消息通过 WebRTC 直连。未配置 TURN，中继受限或对称 NAT 网络可能连接失败。好友号属于设备连接标识，并非正式账号或身份认证。

通话需用户明确允许麦克风／摄像头。视频通话取得本机音频后会自动尝试开启浏览器实时字幕，每次通话只自动启动一次；手动关闭后不会因视频流更新而重新开启。来电未接听前不会自动访问麦克风。语音通话保留手动开启字幕。演示好友只提供本机预览，视频预览获准使用麦克风后同样自动尝试字幕。

字幕使用浏览器 Web Speech API 识别本机声音，并将文字及译文发给对方。每台设备各自识别自己的声音；部分 iPhone 或其他浏览器可能不支持，或与通话麦克风冲突，此时明确提示并自动提供文字字幕输入。通话界面不再提供未配置的自建云端识别选项，也不请求该语音接口。浏览器识别本身仍可能使用浏览器厂商的在线服务，不能保证在所有手机上双向连续识别。识别失败可手动重试，不生成占位译文。

常用语译文内置，其他文字通过 MyMemory 免费 API 翻译；支持双向翻译、额度和网络错误提示、失败重试。不是承诺低延迟的生产级流式语音翻译。语音消息会在浏览器支持时同时尝试转写。图片会在本机缩小后发送。

## 开发与验证

`dist/` 保留浏览器资源；构建会将资源嵌入 Worker ESM `dist/server/index.js`，同时提供可选语音 API。`.openai/hosting.json` 不再声明 `static`。

```sh
npm ci
npm run vendor:peer
npm test
npm run build
```

`dist/vendor/peerjs.js` 由固定版本官方 PeerJS 打包，不依赖外部脚本 CDN。更新时执行 vendor 命令。浏览器安全上下文（HTTPS）是媒体权限和 WebRTC 的必要条件。

## 离线消息（第13版）

托管通过 `.openai/hosting.json` 的 `d1: "DB"` 绑定提供待收信箱，迁移在 `drizzle/`。设备产生256位随机凭证，只发给本站接口；PeerJS好友握手只交换凭证的SHA-256派生地址。双方用新版在线连接一次，互相登记允许的收信关系，此后文字、压缩图片和语音消息可先存入D1，接收方打开页面后每15秒拉取。确认浏览器已持久保存消息ID后才删除服务器副本，重试按发送者/接收者/消息ID去重。待收消息保存最多30天，每个收信箱最多300条，过期数据按批清理。

这不是账号恢复或多设备历史同步：清除本站浏览器数据会丢失本机凭证和历史，需要重新连接好友。没有锁屏推送，视频仍依赖双方在线及TURN可用。数据库免费额度不包含第三方翻译或TURN用量。

验证：`node mailbox.test.mjs` 用真实SQLite执行相同迁移与D1风格接口，覆盖跨设备鉴权、离线投递、补收、确认、去重和过期清理。
